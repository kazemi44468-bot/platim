# پلاتیم

وب‌سایت مستقل برند پلاتیم، ساخته‌شده بر مبنای استانداردهای مخزن `sakhtar`.

## هویت طراحی
- مفهوم مرکزی: دانه
- زبان بصری: Premium Editorial / Natural Luxury
- رنگ‌های اصلی: سبز عمیق، طلایی برنج، عاجی و ذغالی
- تجربه محوری: «سفر یک دانه»

## ساختار
```text
platim/
├── index.html
├── 404.html
├── products/
├── authenticity/
├── origin/
├── quality/
├── shop/
├── wholesale/
├── export/
├── journal/
├── about/
├── contact/
├── assets/
│   ├── css/
│   ├── js/
│   ├── images/logo/
│   ├── icons/
│   ├── videos/
│   └── fonts/
├── components/
├── data/
├── robots.txt
└── sitemap.xml
```

## لوگو
لوگوی پلاتیم را با نام `logo.png` در مسیر `assets/images/logo/` قرار دهید.

## فونت
فونت‌های فارسی پروژه باید در `assets/fonts/` قرار گیرند و در مرحله بعد با `@font-face` محلی به Design System متصل شوند.

این پروژه از Patternهای `sakhtar` به‌عنوان استاندارد فنی استفاده می‌کند، اما هویت و تجربه بصری آن اختصاصی پلاتیم طراحی شده است.
